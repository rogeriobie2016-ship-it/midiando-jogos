# Midiando Jogos

Jogos de educação midiática do Projeto Midiando, projeto de extensão do curso de Jornalismo da UFC.

- `index.html`: página inicial
- `quiz/`: Quiz Midiando, quiz de checagem com pistas
- `antes-do-titulo/`: Antes do Título, aventura 3D (Three.js) sobre o primeiro título de eleitor

Site estático, sem build. Publicado com GitHub Pages a partir da branch `main`.

Para testar localmente:

```bash
python -m http.server 8000
```

e abra http://localhost:8000.
